# fitness-customer-retention-analysis

## Project Overview

This project analyzes customer retention and churn patterns in a fictional fitness business using SQL, Google BigQuery, and Tableau Public.

The goal is to identify factors associated with customer cancellations and provide actionable business recommendations.

## Dashboard

Explore the interactive dashboard:

[View Fitness Customer Retention Dashboard on Tableau Public](https://public.tableau.com/app/profile/kamile.valentim/viz/FitnessCustomerRetentionAnalysis/FitnessCustomerRetentionDashboard#1)

## Key Metrics

- Total customers: 500
- Active customers: 424
- Cancelled customers: 76
- Overall churn rate: 15.2%

## Key Findings

- Basic membership had the highest churn rate (18.64%).
- Premium membership had the lowest churn rate (7.07%).
- Customers training once per week had a churn rate of 19.00%.
- Customers training five times per week had a churn rate of 2.78%.
