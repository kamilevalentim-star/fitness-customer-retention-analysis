# 02 — PREPARE: Data Collection and Organization

## 1. Dataset Overview

The dataset contains 500 fictional customer records from a fitness and personal training company.

The data simulates a 12-month observation period, from January 1, 2025, to December 31, 2025.

## 2. Data Sources

The dataset was synthetically generated for this portfolio project.

No real customer information was used.

## 3. Data Fields

The dataset includes:

- Customer demographics
- Membership plans
- Monthly fees
- Join and cancellation dates
- Customer status
- Weekly training frequency
- Attendance rates
- Payment methods
- Customer lifetime

## 4. Data Organization

The dataset is available in two formats:

- CSV: suitable for SQL and Python analysis.
- Excel: includes customer records and a data dictionary.

## 5. Data Limitations

The dataset is fictional and does not represent actual customer behavior.

The analysis will focus on identifying patterns within the simulated data.

- Validate data types and date formats.
- Identify potential inconsistencies.
- Prepare the dataset for analysis.
